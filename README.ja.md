# gyogy6 Layer Color Viewer（無料版）

[English](README.md) / **日本語** / [简体中文](README.zh-CN.md) / [한국어](README.ko.md)

Substance 3D Painter 用の Python プラグインです。
レイヤーで使っている色を、テクスチャセットごとに一覧で確認できます。
一覧の色はダブルクリックでコピーでき、ほかのレイヤーに貼り付けることもできます。

- バージョン：1.0.0
- 価格：無料（商用利用可・クレジット任意）
- 利用規約：[LICENSE.md](LICENSE.md)（**ダウンロードまたは使用した時点で、この規約に同意したものとみなします**）

| できること | 内容 |
|---|---|
| **色の一覧** | 表示中のレイヤーについて、レイヤー名・どの値か・色見本・HEX（#RRGGBB）を一覧にします。 |
| **コピー** | 行をダブルクリックすると、HEX をコピーします。右クリックで RGB（0〜255）や小数（0〜1）でもコピーできます。 |
| **貼り付け** | コピーした色を、一覧のほかの行や、レイヤーパネルで選んだ Fill レイヤーの Base Color に書き込みます。 |

Fill レイヤーの色のほか、.sbsar のマテリアル・ジェネレーター・フィルターの色パラメーターも一覧に出ます。

## 2. 動作環境

- Adobe Substance 3D Painter 10 以降（Python プラグインが PySide6 で動くバージョン）
- Painter 11.1.3 で動作を確認しています

パネルのツールチップやメッセージは、Painter が日本語で動いているときは日本語、それ以外は英語で表示されます。

## 3. インストール

1. Substance 3D Painter を起動します。
2. 上部メニューの **Python → Plugins Folder** を選ぶと、プラグイン用のフォルダが開きます。
   （通常は `ドキュメント/Adobe/Adobe Substance 3D Painter/python` です。）
3. その中の `plugins` フォルダに、`gyogy6_layer_color_viewer` フォルダを **フォルダごと** コピーします。
4. **Python → Reload Plugins Folder** を選ぶか、Painter を再起動します。

## 4. 使い方

### 4-1. パネルを表示する

1. 上部メニューの **Python** を開き、**gyogy6_layer_color_viewer** にチェックを入れます。
2. **gyogy6 Layer Colors** というパネルが表示されます。
   見つからない場合は、**Window → Views** から探してください。

### 4-2. 色の一覧を見る

プロジェクトを開くと、自動で一覧が表示されます。テクスチャセットごとに見出しがあり、その下に色が並びます。

| 列 | 内容 |
|---|---|
| **Layer** | レイヤーの名前です。グループの中にある場合は `グループ名 / レイヤー名`、エフェクトの場合は `レイヤー名 › エフェクト名` と表示されます。 |
| **Value** | どの値の色かを表します（下の表）。 |
| **Color** | 色見本です。 |
| **HEX** | `#RRGGBB` 形式の色コードです。 |

**Value に表示されるもの**

| 表示 | 意味 |
|---|---|
| `Base Color`、`Emissive` など | Fill レイヤーのチャンネルの色（単色のとき） |
| `マテリアル名 / パラメーター名` | Fill レイヤーに入れた .sbsar マテリアルの色パラメーター |
| `Base Color: ジェネレーター名 / パラメーター名` | チャンネルごとに入れた .sbsar の色パラメーター |
| `[Content] …` | レイヤーの中に追加した Fill エフェクト、ジェネレーター、フィルターの色 |
| `[Mask] …` | マスクの中のエフェクトの色（**Masks** にチェックを入れたときだけ） |
| `Text Color` など | テキスト（フォント）を使ったレイヤーの文字色と背景色 |

**パネル上部の設定**

| 項目 | 動作 |
|---|---|
| **Refresh** | 一覧を読み直します。 |
| **Auto** | レイヤーを変えるたびに自動で一覧を読み直します（初期状態はオン）。 |
| **Filter** | 入力した文字を含む行だけを表示します。レイヤー名、値の名前、`#FFE3` のような HEX の一部で絞り込めます。 |
| **Active set only** | レイヤーパネルで選んでいるテクスチャセットだけを表示します。 |
| **Hidden layers** | 非表示のレイヤーも表示します。初期状態では、目のアイコンがオフのレイヤー（と、非表示のグループの中身）は一覧に出ません。 |
| **Masks** | マスクの中のエフェクトの色も表示します。 |
| **All channels** | Roughness など、色以外のチャンネルの値（灰色）も表示します。 |

### 4-3. 色をコピーする

- **行をダブルクリック**（Value、Color、HEX の列）すると、HEX をクリップボードにコピーします。
- 行を選んで **Copy HEX** を押しても同じです。複数の行を選ぶと、HEX を 1 行ずつ並べてコピーします。
- 行を **右クリック** すると、次の形式でもコピーできます。

  | メニュー | コピーされる文字 |
  |---|---|
  | Copy HEX | `#FFE3D1` |
  | Copy RGB | `255, 227, 209` |
  | Copy float | `1.0000, 0.8902, 0.8196` |

- **Copy list** を押すと、表示中の一覧をタブ区切りのテキストでコピーします。表計算ソフトにそのまま貼り付けられます。

> **補足：** **Layer** の列をダブルクリックすると、そのレイヤーを Painter のレイヤーパネルで選びます。右クリックの **Select layer in Layers panel** でも同じです。

### 4-4. 色を貼り付ける

コピーした色は、パネル下の **Paste color** 欄に入ります。この欄に直接入力しても使えます。
入力できる形は `#RRGGBB`、`#RGB`、`rgb(255, 128, 0)`、`255, 128, 0`、`1.0, 0.5, 0.0` です。
（0〜1 の小数で入力するときは、`1.0` のように小数点を付けてください。小数点がないと 0〜255 として読みます。）

| ボタン | 動作 |
|---|---|
| **Paste to selected rows** | 一覧で選んだ行（複数可）に色を書き込みます。右クリックの **Paste color here** でも同じです。 |
| **Paste to selected layer (Base Color)** | Painter のレイヤーパネルで選んでいる Fill レイヤーの **Base Color** に色を書き込みます。Base Color がオフの場合はオンにします。 |

貼り付けは **Ctrl+Z** で元に戻せます（何行に貼り付けても 1 回で戻ります）。

**例：顔の肌の色を、体のマテリアルにそろえる**

1. 一覧で、顔のマテリアルの肌の色の行をダブルクリックしてコピーします。
2. 体のテクスチャセットで、体のマテリアルの肌の色の行を選びます。
3. **Paste to selected rows** を押します。

## 5. 一覧に出るものと出ないもの

Painter の Python API で読める値だけが一覧に出ます。

| 種類 | 一覧 | 貼り付け |
|---|---|---|
| Fill レイヤー、Fill エフェクトの単色（Base Color など） | 出る | できる |
| Fill レイヤーに入れた .sbsar マテリアルの色パラメーター | 出る | できる |
| チャンネルごとに入れた .sbsar（ジェネレーターなど）の色パラメーター | 出る | できる |
| レイヤーの中のジェネレーター、フィルターの色パラメーター | 出る | できる |
| .sbsar の画像入力に単色を入れたもの | 出る（`… (input)`） | できる |
| テキスト（フォント）の文字色、背景色 | 出る | できる |
| スマートマテリアル | 中身の Fill レイヤーやエフェクトとして出る | できる |
| ペイントレイヤー、ペイントエフェクトで描いた色 | **出ない**（描いた画素は API で読めません） | — |
| 画像（ビットマップ）、ベクター画像の色 | **出ない**（1 つの色ではないため） | — |
| アンカー（参照）の色 | **出ない** | — |
| 画面に表示される最終的な色 | **出ない**（下を見てください） | — |

> **注意：** 一覧の色は、そのレイヤーに **設定されている値** です。
> 不透明度、ブレンドモード、マスク、下のレイヤーとの重なりは計算に入っていないため、画面で見える色と違う場合があります。

HEX が **黄色** で表示されるのは、.sbsar の値が色空間の情報なしで返ってきたものです。.sbsar に入っている値をそのまま表示しています。

## 6. うまくいかないとき

| 症状 | 確認すること |
|---|---|
| Python メニューにプラグインが出ない | `gyogy6_layer_color_viewer` を **フォルダごと** `plugins` フォルダに入れたか確認し、**Python → Reload Plugins Folder** を実行してください。 |
| 一覧が空になる | プロジェクトが開いているか確認してください。表示中のレイヤーに色の値がない場合（ペイントだけのレイヤーなど）も空になります。 |
| レイヤーを変えても一覧が変わらない | **Auto** にチェックが入っているか確認するか、**Refresh** を押してください。 |
| .sbsar の色パラメーターが出ない | .sbsar 側で、そのパラメーターが **色のウィジェット（color）** になっている必要があります。数値（スライダー）のパラメーターは出ません。 |
| 貼り付けで「read only」と出る | その値は書き込みに対応していません。 |

エラーの詳細は **Window → Views → Log** に `[LayerColor]` という表示付きで記録されます。

## 7. 制限事項

- 一覧に出るのは、5 章の「出る」の値だけです。
- **Paste to selected layer (Base Color)** は、Fill レイヤーと Fill エフェクトだけに使えます。マテリアルを入れた Fill レイヤーには使えないので、一覧のパラメーターの行に貼り付けてください。
- 色以外のパラメーター（不透明度、角度など）はコピーできません。
