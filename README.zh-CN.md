# gyogy6 Layer Color Viewer（免费版）

[English](README.md) / [日本語](README.ja.md) / **简体中文** / [한국어](README.ko.md)

Substance 3D Painter 的 Python 插件。
按纹理集（Texture Set）列出图层中使用的颜色，便于一目了然地确认。
双击即可复制颜色，并粘贴到其他图层。

- 版本：1.0.0
- 价格：免费（可商用，署名可选）
- 使用条款：[LICENSE.md](LICENSE.md)（**下载或使用本产品即视为同意本条款**）

| 功能 | 说明 |
|---|---|
| **颜色列表** | 对可见图层列出图层名、对应的值、色块和 HEX（#RRGGBB）。 |
| **复制** | 双击行即可复制 HEX。右键可按 RGB（0–255）或小数（0–1）复制。 |
| **粘贴** | 将复制的颜色写入列表中的其他行，或写入图层面板中所选填充图层的 Base Color。 |

除填充图层的颜色外，.sbsar 材质、生成器和滤镜的颜色参数也会列出。

## 2. 运行环境

- Adobe Substance 3D Painter 10 或更高版本（Python 插件基于 PySide6 运行的版本）
- 已在 Painter 11.1.3 上确认运行

当 Painter 以日语运行时，面板的提示和消息显示为日语，否则显示为英语。

## 3. 安装

1. 启动 Substance 3D Painter。
2. 在顶部菜单中选择 **Python → Plugins Folder**，会打开插件文件夹。
   （通常为 `Documents/Adobe/Adobe Substance 3D Painter/python`。）
3. 将 **整个** `gyogy6_layer_color_viewer` 文件夹复制到其中的 `plugins` 文件夹。
4. 选择 **Python → Reload Plugins Folder**，或重新启动 Painter。

## 4. 使用方法

### 4-1. 显示面板

1. 打开 **Python** 菜单，勾选 **gyogy6_layer_color_viewer**。
2. 会显示 **gyogy6 Layer Colors** 面板。
   如果找不到，请在 **Window → Views** 中查找。

### 4-2. 查看颜色列表

打开项目后会自动显示列表，并按纹理集分组。

| 列 | 内容 |
|---|---|
| **Layer** | 图层名。在组内时显示为 `组名 / 图层名`，效果显示为 `图层名 › 效果名`。 |
| **Value** | 颜色所属的值（见下表）。 |
| **Color** | 色块。 |
| **HEX** | `#RRGGBB` 格式的颜色代码。 |

**Value 列显示的内容**

| 显示 | 含义 |
|---|---|
| `Base Color`、`Emissive` 等 | 填充图层的通道颜色（纯色时） |
| `材质名 / 参数名` | 填充图层中 .sbsar 材质的颜色参数 |
| `Base Color: 生成器名 / 参数名` | 用于单个通道的 .sbsar 的颜色参数 |
| `[Content] …` | 图层内添加的填充效果、生成器、滤镜的颜色 |
| `[Mask] …` | 遮罩内效果的颜色（仅在勾选 **Masks** 时） |
| `Text Color` 等 | 文字（字体）图层的文字颜色和背景颜色 |

**面板顶部的选项**

| 选项 | 作用 |
|---|---|
| **Refresh** | 重新读取列表。 |
| **Auto** | 图层变化时自动重新读取列表（默认开启）。 |
| **Filter** | 只显示包含输入文字的行。可按图层名、值名称或 `#FFE3` 这样的 HEX 片段筛选。 |
| **Active set only** | 只显示图层面板中选中的纹理集。 |
| **Hidden layers** | 也显示隐藏的图层。默认情况下，眼睛图标关闭的图层（以及隐藏组中的内容）不会列出。 |
| **Masks** | 也显示遮罩内效果的颜色。 |
| **All channels** | 也显示 Roughness 等非颜色通道的值（灰色）。 |

### 4-3. 复制颜色

- **双击行**（Value、Color 或 HEX 列）即可将 HEX 复制到剪贴板。
- 也可以选中行后点击 **Copy HEX**。选中多行时，每行复制一个 HEX。
- **右键** 单击行，可按以下格式复制：

  | 菜单 | 复制的文字 |
  |---|---|
  | Copy HEX | `#FFE3D1` |
  | Copy RGB | `255, 227, 209` |
  | Copy float | `1.0000, 0.8902, 0.8196` |

- **Copy list** 会将当前显示的列表复制为制表符分隔的文本，可直接粘贴到电子表格中。

> **提示：** 双击 **Layer** 列会在 Painter 的图层面板中选中该图层。右键菜单中的 **Select layer in Layers panel** 作用相同。

### 4-4. 粘贴颜色

复制的颜色会进入面板下方的 **Paste color** 栏，也可以直接在此输入。
可输入的格式：`#RRGGBB`、`#RGB`、`rgb(255, 128, 0)`、`255, 128, 0`、`1.0, 0.5, 0.0`。
（输入 0–1 的小数时，请加上小数点，如 `1.0`。没有小数点的数字按 0–255 读取。）

| 按钮 | 作用 |
|---|---|
| **Paste to selected rows** | 将颜色写入列表中选中的行（可多选）。右键菜单中的 **Paste color here** 作用相同。 |
| **Paste to selected layer (Base Color)** | 将颜色写入 Painter 图层面板中所选填充图层的 **Base Color**。如果 Base Color 关闭，会将其开启。 |

粘贴可以用 **Ctrl+Z** 撤销（无论粘贴了多少行，一次即可撤销）。

**示例：让脸部的肤色与身体一致**

1. 在列表中双击脸部材质的肤色行进行复制。
2. 在另一个纹理集中选中身体材质的肤色行。
3. 点击 **Paste to selected rows**。

## 5. 可以列出和不能列出的内容

只会列出 Painter 的 Python API 能够读取的值。

| 类型 | 列出 | 粘贴 |
|---|---|---|
| 填充图层、填充效果的纯色（Base Color 等） | 是 | 可以 |
| 填充图层中 .sbsar 材质的颜色参数 | 是 | 可以 |
| 用于单个通道的 .sbsar（生成器等）的颜色参数 | 是 | 可以 |
| 图层内生成器、滤镜的颜色参数 | 是 | 可以 |
| .sbsar 的图像输入设为纯色的情况 | 是（`… (input)`） | 可以 |
| 文字（字体）的文字颜色、背景颜色 | 是 | 可以 |
| 智能材质 | 作为其中的填充图层和效果列出 | 可以 |
| 用绘画图层、绘画效果画出的颜色 | **否**（无法通过 API 读取绘制的像素） | — |
| 位图、矢量图像的颜色 | **否**（不是单一颜色） | — |
| 锚点（引用）的颜色 | **否** | — |
| 屏幕上显示的最终颜色 | **否**（见下文） | — |

> **注意：** 列表中的颜色是该图层 **设置的值**。
> 不透明度、混合模式、遮罩以及下方图层的叠加均未计算在内，因此可能与屏幕上看到的颜色不同。

HEX 显示为 **黄色**，表示该 .sbsar 的值返回时不带颜色空间信息，按 .sbsar 中保存的值原样显示。

## 6. 故障排除

| 问题 | 检查事项 |
|---|---|
| Python 菜单中没有插件 | 确认已将 **整个** `gyogy6_layer_color_viewer` 文件夹放入 `plugins` 文件夹，然后执行 **Python → Reload Plugins Folder**。 |
| 列表为空 | 确认已打开项目。可见图层没有颜色值时（仅有绘画的图层等）列表也会为空。 |
| 图层变化后列表不更新 | 确认已勾选 **Auto**，或点击 **Refresh**。 |
| 没有显示 .sbsar 的颜色参数 | 该参数在 .sbsar 中必须使用 **颜色控件（color）**。数值（滑块）参数不会列出。 |
| 粘贴时显示 "read only" | 该值不支持写入。 |

错误详情会以 `[LayerColor]` 标记记录在 **Window → Views → Log** 中。

## 7. 限制

- 只会列出第 5 节中标为"是"的值。
- **Paste to selected layer (Base Color)** 只能用于填充图层和填充效果。对于放入了材质的填充图层，请粘贴到列表中对应参数的行。
- 无法复制非颜色参数（不透明度、角度等）。
